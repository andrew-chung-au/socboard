# Decision: A command-line flag, not an environment variable, lets the container image bind a non-loopback address

One file per choice that may be revisited. **Status: proposed.** The human approved this decision with issue #142 (body hash `70612526067af7bd958148dd1306556ee474a2afbfe6b4a8ff516fb2eac3d99d`); only the human sets `approved` here. Heavy tier: it relaxes a security limit.

- **Decision:** `python -m socboard.server` accepts one command-line flag, `--allow-non-loopback-host`, that allows a non-loopback host. Only the container image's start command passes it, and no environment variable can switch it on. The host value still comes from `SOCBOARD_HOST`. Without the flag, every host except `127.0.0.1`, `localhost` and `::1` exits 2 as before. With the flag, `SOCBOARD_HOST` must be an IP address or one of those three names; a name, an empty string, whitespace or a URL is refused.
- **Reason:** `make backend-run` and `scripts/backend_probe.py` both read the inherited environment, so an environment-variable opt-in could be set by accident in a developer's shell and `make backend-run` would then bind publicly. A flag has to be typed into the start command, which only the image has. This keeps the 2026-11-12 ruling that `make backend-run` stays loopback-only.
- **Alternatives:** an environment variable with an exact value (refused: the Makefile recipe and the probe inherit the environment, so the refusal case cannot hold); a second entry module for the container (no flag parsing, but two entry points to keep in step); removing the restriction (rejected by the human's ruling).
- **Trade-offs:** `server.py` gains argument parsing it did not have (stdlib `argparse`, abbreviations off, so a value or an unknown argument exits 2 with a usage line). The Dockerfile (D10, not yet filed) must pass the flag; a container started another way fails closed with exit 2 and a message, which is the safe direction. `resolve_bind` takes the opt-in as a second argument that defaults to off, so the probe's call is unchanged.
- **Evidence:** Issue #142 (body and comments); `socboard/server.py` (`resolve_bind`, `parse_flags`); `Makefile` `backend-run` and `backend-stop`; `scripts/backend_probe.py`; `_docs/planning/roadmap-3-deploy.md`.
